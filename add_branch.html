Partner Portal Access Hours

Restrict a partner’s portal access to a branch time window and blocked weekdays. Hours and days are stored on this branch. The employee only has an on/off flag (Restrict Portal Access).

What it isA branch-level office-hours rule for the partner portal, using Asia/Kolkata (IST).
What it doesWhen Restrict Portal Access is on for an employee linked to this branch, they can use the portal only between Access Start and Access End, and not on Access Not Allowed Days.
How it worksEmpty start and end skips the hour check (blocked days still apply). Only start set denies access before that time. Only end set denies access after that time. Both set is a same-day window — Access Start must be before Access End.
Best ForLimiting staff portal use to working hours and excluding weekly offs or weekends.
  1. Set Access Start and Access End for the allowed daily window (IST).
  2. Pick Access Not Allowed Days for weekly offs or weekends.
  3. On each employee, turn on Restrict Portal Access to enforce this branch rule.
!

Important Note

Access Start must be before Access End (same-day window, no overnight). Time is checked in IST (Asia/Kolkata). The client portal is not affected.
