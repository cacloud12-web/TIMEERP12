SMTP Configuration

SMTP Configuration Guide

All fields marked as required must be filled before saving. If a required field is left empty, you will see a validation message such as 'Email' is required!

Email *

Enter the email address that will be used to send emails from the application. e.g. yourname@company.com

Password *

Enter the password for the email account above. For Gmail or similar providers, use an app-specific password if 2FA is enabled. e.g. your email account password or app password

Host *

Enter the SMTP server address provided by your email provider. e.g. smtp.gmail.com, smtp.office365.com

Port *

Enter the SMTP port number. Use 587 for TLS or 465 for SSL, as recommended by your provider. e.g. 587

Default

Optional. Check this to use this configuration as the default for sending emails.

IMAP Enabled

Optional. Enable this if IMAP should be used for mailbox sync.

IMAP Host

Optional. IMAP server host, required only when IMAP is enabled. e.g. imap.gmail.com

IMAP Port

Optional. IMAP server port, required only when IMAP is enabled. e.g. 993
