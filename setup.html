Frequently asked questions

Quick answers for administrators configuring TIME ERP.

Open Setup → Add Branches (Branch Data). Complete Basic Details, then Billing, Payment, Social Media, and Support as needed, and save. Use the branch when adding employees and leave quotas.
First create leave types under Add Leaves. Manually: Leave Quota, set leave type, branch, designation, and annual count. In bulk: Leave Credit/Debit and upload Excel via + beside Remarks.
Open Setup → Add SMTP and configure your provider (Gmail, Yahoo, Rediff, or Outlook). Save and send a test email so notifications and documents can be delivered.
Manual: Payroll → Account setting → Pay details. Bulk: Import utility → HRMS → upload the pay details Excel. Validate a sample employee before the first payroll run.
